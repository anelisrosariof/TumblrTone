# Tumblr Tone

A little digital darkroom for your phone: live camera filters (2014, Amaro, Nashville, Bleach Bypass, Digicam and film looks), adjustments, grain, light leaks, dust, date stamps and frames. Everything runs on-device.

Open https://anelisrosariof.github.io/TumblrTone/ in Safari and use Share → Add to Home Screen to make it feel like an app.
